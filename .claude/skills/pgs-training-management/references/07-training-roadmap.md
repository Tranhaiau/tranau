# Reference 07 — Lộ trình Đào tạo & Plan Training Quý/Năm

> **Khi nào load:** Trưởng phòng cần lập plan training năm/quý;
> hoặc khi user hỏi "Lộ trình KTV mới lên L4 mất bao lâu", "Plan training Q3/2026 cho tổ".

---

## 1. Triết lý lộ trình

Lộ trình đào tạo PGS được xây dựng quanh 3 nguyên tắc:

1. **Time-based + Evidence-based:** thời gian on-job tối thiểu (cứng) + bằng chứng KPI (cứng).
2. **Modular path:** từng module rõ ràng, có prerequisites, không học nhảy cóc.
3. **Personalized branching:** lộ trình rẽ nhánh theo điểm mạnh/yếu cá nhân (general vs specialist).

## 2. Lộ trình chuẩn theo bộ phận

### 2.1 Lộ trình KTV (từ L1 → L7)

```
L1 (Trainee) ── 6m ──→ L2 (Junior)
                 ↓ 6m
                 L3 (Mid) ─── 12m ──→ L4 (Senior)
                                       ↓ 12m
                                       L5 (Expert)
                                       ↓ 12m
                                       L6 (Lead) ─ 12m ─→ L7 (Master)
                                       │
                                       └── nhánh chuyên biệt:
                                            ├─ KTV chuyên hybrid/EV
                                            ├─ KTV chuyên đại tu
                                            └─ KTV chuyên chẩn đoán điện
```

**Tổng thời gian L1 → L7:** ~5 năm (60 tháng) cho NS có năng lực tốt.

                                       ↓ 12m

                                            ├─ CVDV chuyên VIP/Fleet

```
L1 (Trainee) ── 6m ──→ L2 (Junior — đặt PT theo SOP)

import pandas as pd
from datetime import datetime

def gen_quarterly_training_plan(chi_nhanh, quarter, eval_records, ns_master):
    """
    Tạo plan training cho 1 quý dựa trên đánh giá kỳ trước.
    """
    plan = {
        'chi_nhanh': chi_nhanh,
        'quarter': quarter,
        'ngay_lap_plan': datetime.now().date().isoformat(),
        'training_groups': []
    }

    # Group 1: NS pattern lỗi → module booster
    weak_ns = [r for r in eval_records
               if r['nhom_xep_hang'] in ('Cần cải thiện', 'Đáy nhóm — cần can thiệp')]

    for ns in weak_ns:
        weak_kpis = ns.get('weak_kpis', [])
        for kpi in weak_kpis:
            modules = map_kpi_to_modules(kpi['kpi'], ns['bo_phan'])
            plan['training_groups'].append({
                'group_type': 'KPI_remediation',
                'ma_NS': ns['ma_NS'],
                'modules': modules,
                'priority': 'high',
                'target_date': add_months(quarter, 1)
            })

    # Group 2: NS đủ điều kiện thăng cấp → module level mới
    promotion_candidates = [r for r in eval_records
                             if r.get('eligible_for_promotion')]
    for ns in promotion_candidates:
        target_level = ns['level_hien_tai'] + 1
        modules_next_level = get_modules_for_level(ns['bo_phan'], target_level)
        plan['training_groups'].append({
            'group_type': 'Promotion_path',
            'ma_NS': ns['ma_NS'],
            'modules': modules_next_level,
            'priority': 'medium',
            'target_date': add_months(quarter, 3)
        })

    # Group 3: NS mới onboarding
    new_hires = [n for n in ns_master if (datetime.now().date() - n['ngay_vao_PGS']).days <= 90]
    for ns in new_hires:
        plan['training_groups'].append({
            'group_type': 'Onboarding',
            'ma_NS': ns['ma_NS'],
            'modules': get_onboarding_modules(ns['bo_phan']),
            'priority': 'critical',
            'target_date': add_months(quarter, 1)
        })

    # Group 4: Refresh module annually cho NS L3+
    high_level_ns = [n for n in ns_master if n['level_hien_tai'] >= 3]
    refresh_modules = get_annual_refresh_modules(quarter)
    plan['training_groups'].append({
        'group_type': 'Annual_refresh',
        'ma_NS_list': [n['ma_NS'] for n in high_level_ns],
        'modules': refresh_modules,
        'priority': 'low',
        'target_date': add_months(quarter, 3)
    })

    # Group 5: Hãng có module mới / triệu hồi
    hang_new_modules = check_hang_updates()
    if hang_new_modules:
        plan['training_groups'].append({
            'group_type': 'OEM_updates',
            'modules': hang_new_modules,
            'ma_NS_list': 'all_KTV_L2+',
            'priority': 'high',
            'target_date': add_months(quarter, 2)
        })

    return plan
```

### 5.2 Tính tổng giờ training cần thiết

```python
def calculate_training_hours(plan, module_master):
    """
    Tổng giờ training cần cho cả quý.
    """
    total_h = 0
    by_group = {}
    for g in plan['training_groups']:
        h_per_NS = sum(module_master.loc[m, 'thoi_luong_h'] for m in g['modules'])
        n_NS = 1 if 'ma_NS' in g else len(g.get('ma_NS_list', []))
        group_h = h_per_NS * n_NS
        total_h += group_h
        by_group[g['group_type']] = by_group.get(g['group_type'], 0) + group_h
    return {'total_h': total_h, 'by_group': by_group}
```

def schedule_training_sessions(plan, workshop_calendar, target_date_per_group):

- 1 onboarding wave (cho NS mới)

### 8.2 Tự động tính milestone date

```python
def estimate_promotion_date(ma_NS, target_level, current_state):
    """
    Estimate ngày NS đủ điều kiện thăng cấp dựa trên:
    - On-job months còn thiếu
    - Module còn thiếu × thời gian học
    - KPI gap × thời gian cải thiện
    """
    factors = []

    # 1. On-job
    months_needed = ON_JOB_REQ[current_state['bo_phan']][target_level]
    months_have = current_state['on_job_months_at_current_level']
    if months_have < months_needed:
        factors.append(('on_job', (months_needed - months_have) * 30))

    # 2. Modules
    n_modules_left = current_state['n_modules_required'] - current_state['n_modules_completed']
    if n_modules_left > 0:
        factors.append(('modules', n_modules_left * 30))   # 1 module ~ 1 tháng

    # 3. KPI gap
    if current_state['ftf_rate'] < KPI_REQ[target_level]['ftf_min']:
        factors.append(('kpi_improvement', 60))   # cần 60 ngày + training

    # Estimate = max of factors
    days_needed = max(d for _, d in factors)
    return pd.Timestamp.now() + pd.Timedelta(days=days_needed)
```

## 9. Quy tắc bất biến

1. **Lộ trình PHẢI có cả time-based + evidence-based** — không "thăng vì thâm niên".
2. **Module có prerequisites** — không học nhảy cóc.
3. **Plan quý phải lập từ data eval kỳ trước** — không "feel-based".
4. **NS mới onboarding 90 ngày bắt buộc** — Hook H7 enforce mẫu chưa đủ kết luận.
5. **Annual refresh bắt buộc cho NS L3+** — chống stagnation.
6. **OEM update phải gấp** — Hãng triệu hồi → train trong 2 tuần.
7. **Plan năm phải có ngân sách + KPI rõ** — không "best effort".

## 10. Edge cases

| Tình huống | Cách xử lý |
|---|---|
| NS muốn nhảy cấp (L1 → L3) | Không cho. Phải qua L2 đầy đủ. |
| NS có chứng nhận hãng vượt level | Vẫn theo lộ trình PGS, nhưng được miễn 1-2 module liên quan |
| Plan quý conflict với cao điểm xưởng | Dời sang quý sau hoặc tổ chức ngoài giờ + bonus cho NS |
| NS từ đại lý PGS khác chuyển đến | Công nhận lịch sử eval cũ, không bắt làm lại từ đầu |
| Hãng release module mới giữa quý | Insert vào plan ngay, có thể pause module thường |
| NS đạt L4 nhưng không muốn lên L5 | Tôn trọng, chỉ refresh để duy trì L4 |
| Plan vượt ngân sách | Ưu tiên: critical (OEM, onboarding) > high (KPI remed) > medium (promotion) > low (refresh) |
| 1 NS rớt 2 quý liên tiếp dù training | Mời họp 1-1 + plan cải thiện 30 ngày + nếu fail tiếp → đánh giá lại định hướng |
